## 栏目初衷
考虑到18级和22级的培养方案改版，以及多版本的github项目的分散性，此栏目将以22版培养方案为主，整合相关内容，以保证时效性(目前适配至22级)。

> 使用说明: 由于教材等改版，故对往届网站改版前的部分内容作删减，并与新内容合并。但此外部分内容难免与当前存在一定偏差，仅供参考，请读者自行选择性使用。
