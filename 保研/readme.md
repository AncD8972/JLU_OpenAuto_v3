# 必看
## 文件夹介绍
该部分为 **保研** 经验区，每一个文件夹都对应着一位学长学姐的珍贵经验，希望后来的学弟学妹们，都能够寻着前人的脚步，走的更远。

保研加分文件夹下对应着本学院的加分细则和认可的竞赛名单。

文件夹内会有一个 **主文件夹**。这个文档会按照固定的结构记录了学长学姐的个人情况和保研相关事项。如果学弟学妹觉得对自己有帮助，可以点击 **一级标题** 跳转到相应文件夹下，详细了解。

以主文件夹 [2022年夏令营](./zhyang/2022年夏令营.md) 为例，至少包含以下内容：
1. 个人情况，如排名、奖项等等
2. 夏令营 / 预推免的报名与录取情况
3. 夏令营/预推免面试经历
4. 经验之谈

如果学弟学妹想快速了解目标院校的面试 / 笔试情况，可在本文件内搜索学校名称，查到往届学长学姐的经历。
我们会无私的分享自己保研时收集的资料。
希望这里能够有JLU自动化保研er想找寻的一切。

## 特殊计划简要说明(时效至24年保研)
### 本校直博
该名额会在第五学期按专业发放名额数，25%线内同学均可申报；
按往届来说会**占用**本专业常规推免名额，且需联系本学期有本校直博招生名额的导师接收。
### 常规推免
"13%保研线"的线内名额，每年可能不同专业有少量新增名额，统称常规推免(学校提供的保研资格，保本校保外校均可)
### 特殊计划
21级保研项目有国防科工补偿(保研至国防科大,详见A学姐)、工程硕博(保研本校，含本院名额与人工智能学院名额)、名师计划(保研本校)；
该部分属于特殊保研计划，**不占用**常规推免名额，线后的同学(需25%前)参加通过计划中的推免流程后可直接推免至计划学校。后续培养方案可能有相应保研计划的相应特色，需研究当年政策(比如，参军入伍/企业联培/支教等等)。
